🎬 Omni Describe

Runs on this machine's GPU and generates descriptions for your movie/TV library. One-time install, then it starts automatically and lives at http://localhost:5050/.

Open PowerShell (not as admin needed) and run:

irm http://192.168.1.110:30817/get/install.ps1 | iex

Requires git and Python 3.10+ already installed. Registers a startup shortcut, so it'll be running next time you log in too.

Open a WSL terminal and run:

curl -fsSL http://192.168.1.110:30817/get/install.sh | bash

Requires git, python3/python3-venv, and (for GPU use) the NVIDIA CUDA on WSL driver already installed. No auto-start on WSL — re-run the same command (or just python omni_service/app.py from the install dir) each time you want it running.
